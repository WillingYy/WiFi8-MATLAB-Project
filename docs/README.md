# Project Documents / 项目文档

This folder contains shared modelling assumptions and report materials.
本文件夹存放共同模型约定与报告材料。

## Planned documents / 计划文档

- model_agreement.md
  Shared model, timing rules and assumptions.
  共同模型、计时规则与假设。

- experiment_plan.md
  Experiment scenarios, parameters and metric definitions.
  实验场景、参数与指标定义。

- references.md
  Verified references and literature comparison.
  已核查的参考文献与文献对比。

- report/
  Editable report sections.
  可编辑的报告章节。

## Ownership / 负责人

The team lead maintains the shared agreements.
Member A maintains the literature and references.
Members B, C and D provide and verify technical details.

组长维护共同约定，成员 A 维护文献，
成员 B、C、D 提供并核对技术细节。

Changes to shared assumptions must be communicated to affected members.
共同假设修改后，必须通知受影响成员。
