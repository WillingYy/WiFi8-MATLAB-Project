# Project documents

This folder preserves modelling notes, contribution handovers,
and validation records supplied by team members.

The paths below are relative to this directory.

| File | Content |
| --- | --- |
| `Coordinated_Scheduling_Methods.md` | Coordinated scheduling description |
| `Handover_To_Leader.md` | Scheduler contribution handover |
| `Validation_Record.md` | Submitted scheduler validation record |
| `docs/B_model.md` | Shared engine and model notes |
| `docs/interface_spec.md` | Submitted interface specification |
| `docs/B_validation.md` | Submitted engine validation notes |
| `docs/B_demo_output.txt` | Earlier demonstration output |
| `docs/AI_B.md` | Member B's AI-use record |

## Using these documents

Contribution documents preserve their original submission context and may
describe earlier integration stages.

For current file locations, execution instructions, and verified demonstration
values, use the [main README](../README.md) and executable code.

Use the final report for the consolidated experimental analysis,
limitations, references, and group-wide AI-use disclosure.
Individual AI-use notes cover only the corresponding member's contribution.

Original handover documents are retained to preserve the development record.
