## Figure requirements / 图表要求

Use English labels in final report figures.
最终报告图表使用英文标签。

Include axis labels, units and clear legends.
标明坐标名称、单位和图例。

Use consistent colours for the three methods across figures.
三种方法在不同图中使用一致的颜色。

Explain any error bars or confidence intervals.
说明误差条或置信区间的含义。

Save editable FIG files and publication-quality exports.
保留可编辑的 FIG 文件及清晰的导出图片。

Each figure must be traceable to its source data and configuration.
每张图必须能够追溯到对应原始数据与参数配置。

Plotting scripts should read saved results rather than rerun simulations.
绘图脚本应读取已保存结果，无需重新运行仿真。
